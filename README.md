# LASHTABEGA_METRICS

Программная система расчёта продуктовых метрик сервиса управления ценниками.

## Назначение проекта
Проект предназначен для автоматизированного расчёта продуктовых метрик сервиса управления ценниками на основе данных из витрины price, POS-витрин и связанных источников.

## Используемые технологии
- Python
- PostgreSQL
- DBeaver Community
- Apache Superset
- FastAPI
- Docker
- Git / GitHub

## Основные функции
- интеграция и загрузка данных;
- ETL-обработка и нормализация;
- контроль качества данных;
- расчёт продуктовых метрик;
- ведение дерева и реестра метрик;
- публикация аналитики в Apache Superset;
- мониторинг событий и ошибок.

## Структура проекта
- `src/` — основной код проекта
- `sql/` — SQL-скрипты
- `docs/` — документация и диаграммы
- `tests/` — тесты
- `superset/` — BI-конфигурация
